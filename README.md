# Build Single Page Web Apps in 2026

Open `index.html` in a browser to view the student lesson.

The page is a self-contained HTML/CSS/JavaScript tutorial and includes:
- Responsive layout
- Dark/light mode saved with localStorage
- Smooth CSS animation
- Interactive progress-bar demo
- Explanation of how HTML, CSS and JavaScript work
- Animation performance guidance
- Reduced-motion support
- Low-memory usage practices
- Student project challenge

## GitHub Pages
Upload `index.html` to your repository, enable GitHub Pages, and use the generated Pages URL as the lesson link on your portfolio.
