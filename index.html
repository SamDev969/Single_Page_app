Build Single Page Web Apps in 2026

Learn how HTML, CSS and JavaScript work together to create fast, responsive and user-friendly single page web apps—with smooth animations, dark mode and low memory usage.

CSS animation: smooth movement without JavaScript.

1. What is a Single Page Web App?

A single page web app (SPA) is a website where the browser loads one main page and JavaScript changes parts of that page without constantly loading new HTML documents.

HTML

Creates the structure: headings, buttons, sections, forms and content.

CSS

Controls layout, colors, responsive design, dark mode and animations.

JavaScript

Adds behavior: clicks, counters, theme switching and dynamic updates.

3. How the HTML is Made

HTML gives the application meaningful structure. Prefer semantic elements such as header, main, section, button and footer.

<main>
  <section>
    <h2>My App</h2>
    <p>Application content goes here.</p>
    <button id="add">Increase</button>
  </section>
</main>

Good HTML improves accessibility, organization and maintainability.

4. How the CSS is Made

CSS creates the visual design and keeps animation work efficient.

:root {
  --bg: #f6f8fc;
  --text: #172033;
}

body.dark {
  --bg: #0b1020;
  --text: #edf2ff;
}

.orb {
  animation: float 3s ease-in-out infinite;
}

@keyframes float {
  50% { transform: translateY(-14px); }
}
Best practice: Animate transform and opacity where possible. Avoid repeatedly animating expensive layout properties such as width, height, top and left.

5. How Dark Mode is Made

This lesson uses CSS variables. JavaScript only adds or removes one class from the body.

// JavaScript
document.body.classList.toggle("dark");

This approach is simple because the colors are controlled in one place—the CSS variables. You can also save the user's choice with localStorage.

6. How JavaScript Controls the App

let progress = 0;

add.addEventListener("click", () => {
  progress = Math.min(progress + 10, 100);
  count.textContent = progress + "%";
  bar.style.width = progress + "%";
});

reset.addEventListener("click", () => {
  progress = 0;
  count.textContent = "0%";
  bar.style.width = "0%";
});

The important idea is state → update → display. Keep the state small and update only the DOM elements that actually changed.

7. Best Practices for Smooth Animations

Use transform

Prefer transform and opacity for many animations.

Keep it subtle

Short, purposeful animations feel faster than excessive effects.

Respect reduced motion

Users can request less motion. Your site should respect that preference.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

8. How to Keep Memory Usage Low

  • Remove event listeners and timers that are no longer needed.
  • Do not create thousands of DOM elements when a smaller structure will work.
  • Avoid large images; resize and compress assets before adding them.
  • Reuse DOM elements instead of repeatedly creating and deleting them.
  • Avoid unnecessary JavaScript libraries for simple features.
  • Use browser developer tools to inspect memory and performance when an app becomes slow.

10. Quick Summary

Remember: HTML builds the structure, CSS creates the experience, and JavaScript creates the interaction. Good web apps use all three together without making the browser do unnecessary work.
